# 승진 평정 계산기 (시·도별 · 중등/초등)

「교육공무원 승진규정」(경력·근무성적·연수성적평정, 공통가산점)과 시·도교육청의 「가산점 부여기준」(선택가산점)을 바탕으로 한 간이 계산기입니다.

| 시·도 · 학교급 | 선택가산점 기준 |
|---|---|
| 인천 중등 | 인천광역시교육청 공고 제2026-319호 (2026. 7. 24. 개정) |
| 그 밖의 시·도, 초등 | 준비 중 (경력·근평·연수·공통가산점만 계산) |

- `index.html` 하나로 동작합니다. 브라우저로 열거나 GitHub Pages로 게시하면 됩니다.
- 본인 인사기록카드를 보며 승진 점수를 관리하는 계산기입니다. 입력 화면이 인사기록카드 순서(1. 신상사항 ~ 20. 임용전 경력)대로 되어 있어, 카드를 위에서부터 보며 점수에 쓰이는 칸만 채우면 됩니다. 점수와 무관한 칸은 한 줄 안내로 접혀 있습니다. 다음을 모두 계산해 총점을 보여줍니다.
  - 경력평정 (기본 15년 + 초과 5년, 가·나·다 경력)
  - 근무성적평정 (최근 5년 중 유리한 3년, 반영비율 34:33:33)
  - 연수성적평정 (직무연수·자격연수, 연구대회 입상, 학위)
  - 공통·선택가산점 (항목·그룹 상한 적용)
- 경력·근무성적·연수성적 기준값은 화면의 ‘평정 기준값’에서 고칠 수 있습니다. 「교육공무원 승진규정」(2026. 6. 16. 개정)과 인천 평정업무 처리요령으로 확인하세요.
- 입력 내용은 사용자의 브라우저(localStorage)에만 저장되며 서버로 전송되지 않습니다.
- **CSV로 저장 / CSV 불러오기**: 입력한 모든 내용(기준값 수정 포함)을 CSV 파일로 저장하고, 다음에 그 파일을 불러와 이어서 관리할 수 있습니다. 엑셀에서 열어 수정한 뒤 다시 저장한 파일(CP949)도 불러올 수 있습니다.
  - CSV 열: `구분, 값1~값5, 설명`. `구분`은 경력평정·근무성적·직무연수·연구대회·학위·가산점경력·직무연수학점·실습학기제·단일값·기준값·평정기준일이며, 맨 위 `결과` 줄은 읽기용 요약이라 불러올 때 무시합니다.
- 공식 평정 결과가 아니며, 중복 경력은 경고만 표시합니다.

## GitHub Pages로 게시하기

`.github/workflows/pages.yml`이 `index.html`을 GitHub Pages에 자동 배포합니다. 처음 한 번만 설정하세요.

1. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
2. **Actions** 탭에서 ‘GitHub Pages 배포’ 워크플로를 선택하고 **Run workflow**를 누릅니다. (이후에는 `main` 또는 현재 기본 브랜치에 푸시할 때마다 자동 배포됩니다.)
3. 배포가 끝나면 `https://violetwizard-lim.github.io/promotion/` 주소로 접속할 수 있습니다.

> 배포 환경(github-pages)은 기본적으로 저장소의 기본 브랜치에서만 배포를 허용합니다. 기본 브랜치를 `main`으로 바꾸면 워크플로도 그대로 동작합니다.

## 시·도·학교급 추가하기

`index.html`의 `RULESETS`에 `"<시도>:<학교급>"` 키(예: `"gyeonggi:mid"`, `"incheon:ele"`)로 기준을 추가합니다. 해당 시·도교육청의 「가산점 부여기준(중등/초등)」 고시문을 바탕으로 다음을 채웁니다.

- `groups`: 선택가산점 그룹과 그룹 상한
- `items`: 기간으로 매기는 항목 (월·일 평정점, 항목 상한, 구역별 점수, 적용 기간)
- `schools`: 학교명 검색용 지정 학교 목록 (도서·벽지, 특수지역 등)
- `pairs`: 중복 경력 택일 대상
- `groupCap`, `counts`: 시기별 상한 변경, 건수·등급으로 매기는 항목

## 선생님들과 공유하기

GitHub Pages 주소(`https://violetwizard-lim.github.io/promotion/`)를 그대로 공유하면 됩니다.

- 입력한 내용은 각자의 브라우저에만 저장되고 서버로 전송되지 않습니다. 같은 주소를 여러 명이 써도 서로의 내용은 보이지 않습니다.
- 기기를 바꾸거나 보관하려면 **CSV로 저장**한 파일을 **CSV 불러오기**로 다시 엽니다.
- 공식 평정 결과가 아니라 본인 점수 관리를 위한 간이 계산 도구입니다.
