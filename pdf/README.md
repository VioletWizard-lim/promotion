# 가산점 기준 원문 (PDF)

계산기에 넣을 시·도교육청 「가산점 부여기준」·평정업무 처리요령 원문을 올리는 폴더입니다.

## 올리는 방법
1. GitHub에서 이 `pdf` 폴더로 들어갑니다.
2. **Add file → Upload files**로 PDF를 끌어다 놓고 **Commit changes**를 누릅니다.
   - 웹 업로드는 파일 하나당 25MB까지입니다. 넘으면 필요한 쪽만 잘라서 올려주세요.

## 파일 이름 (권장)
`시도_학교급_연도.pdf` — 예: `경기_중등_2025.pdf`, `인천_초등_2022.pdf`

## 참고
- 이 폴더의 파일은 계산기 사이트(GitHub Pages)에는 올라가지 않습니다. 저장소에서만 보입니다.
- 저장소가 공개 상태라 누구나 내려받을 수 있습니다. 교육청이 공개한 고시·처리요령만 올려주세요.
